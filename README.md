# Aayush Upadhyay — Tech Athlete Portfolio

> **BUILD. TRAIN. COMPETE. IMPROVE.**

A modern, dark-themed personal portfolio built around a **sports-performance analytics** aesthetic, combining software engineering with the mindset of continuous improvement.

The portfolio showcases my **projects, technical skills, education, certifications, achievements, and competitive experiences** through a data-driven interface designed to feel more like an athlete performance dashboard than a traditional developer portfolio.

* 🏆 **Competitive & achievement-focused** portfolio design
* 💻 Featured software engineering projects
* ☁️ Google Cloud certification
* 📊 Performance-inspired statistics and visualizations
* 🎯 Interactive project case studies
* 📱 Responsive design across desktop and mobile
* ⚡ Smooth animations and transitions
* 🔗 Direct links to GitHub, LinkedIn, LeetCode, and other profiles

## 🛠 Tech Stack

| Technology        | Purpose                        |
| ----------------- | ------------------------------ |
| **React 18**      | UI development                 |
| **TypeScript**    | Type-safe development          |
| **Vite**          | Development and build tooling  |
| **Tailwind CSS**  | Styling and responsive layouts |
| **Framer Motion** | Animations and interactions    |
| **Lucide React**  | Interface icons                |

The portfolio is a **static frontend application** with no backend or database.

## 📁 Project Structure

```text
src/
├── components/    Reusable UI components
├── sections/      Portfolio sections
├── data/          Personal content and project data
├── hooks/         Custom React hooks
└── types/         Shared TypeScript types

public/
└── assets/        Resume, certificates, and static assets
```

### Updating Content

Most portfolio content is centralized in `src/data/`.

To update projects, skills, certifications, education, or other personal information, edit the relevant data files rather than modifying the UI components.

To replace the resume or other documents, update the corresponding files in `public/assets/`.

## 🚀 Run Locally

### Prerequisites

* Node.js 18+
* npm

### Installation

```bash
git clone https://github.com/AayushUpadhyay1210/portfolio.git
cd portfolio
npm install
npm run dev
```

Vite will provide a local development URL, typically:

```text
http://localhost:5173
```

### Production Build

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## ☁️ Deployment

The project is configured for deployment as a static Vite application.

### Vercel

1. Import the repository into Vercel.
2. Select **Vite** as the framework preset.
3. Use `npm run build` as the build command.
4. Use `dist` as the output directory.
5. Deploy.

No environment variables are required.

## 🎨 Design Philosophy

The portfolio is intentionally built around the idea of **performance**.

Instead of presenting skills as a conventional list, the interface uses visual language inspired by:

* Sports analytics dashboards
* Performance statistics
* Competition scorecards
* Training metrics
* Progress tracking

The goal is to represent software development as an iterative process:

**Build → Train → Compete → Improve**
